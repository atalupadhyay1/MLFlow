# Research → Report

## Steps
1. Restate the question; list sub-questions + assumptions; confirm scope briefly if ambiguous.
2. Plan sources per sub-question (official docs/primary > analyst > blog). Note search phrases.
3. Gather: web_search + web_fetch (max 12 sources unless told otherwise).
   Save source notes FIRST to reports/<slug>-sources.md: URL, date, 2–3 key claims each.
   Do not draft the report until this file exists.
4. Cross-check: any load-bearing claim needs 2 sources; record disagreements honestly.
5. Write reports/<slug>.md with: Executive summary (≤5 lines) · Method & sources ·
   Findings (cited) · Comparison table (if options) · Costs & assumptions (dated, explicit) ·
   Risks & unknowns (label UNKNOWN) · Recommendation + confidence (low/med/high) +
   what-would-change-it · Sources list.
6. Deliver: 5-line summary on the channel + the file path. Full text stays in the file.

## Guardrails
- No citation = delete the claim or label UNKNOWN. Never invent prices/dates/features.
- Date-stamp all costs; footer: "Verify figures before acting."
